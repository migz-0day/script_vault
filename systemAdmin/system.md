# System.sh
It`s a script that gives information about your linux distro including user,hostname,cpu information and disk usage.This information gets written to sys_report.txt

# installation and use
clone the repo
```bash
 git clone https://github.com/migz-0day/script_vault.git
 cd script_vault/systemAdmin
```
or 
```bash
curl -O https://raw.githubusercontent.com/migz-0day/script_vault/master/systemAdmin/system.sh
```
to only get this file
Then 
```bash
 chmod +x system.sh
```
to give execusion permission
